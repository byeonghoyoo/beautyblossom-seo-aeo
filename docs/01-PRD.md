# 1. 목표와 원칙

## 한 문장 목표

뷰티블라썸 5개 언어의 Google SEO·AEO 기술 신호를 정리하고, 별도 네이버 웹사이트 기술 검증과 승인된 이미지 시험을 진행하되 기존 디자인·기능·속도를 보호합니다.

## 대상

- 한국어: `beautyblossom.kr`
- 영어: `en.beautyblossom.kr`
- 일본어: `jp.beautyblossom.kr`
- 중국어 간체: `cn.beautyblossom.kr`
- 중국어 번체: `tw.beautyblossom.kr`

태국어는 사용자가 기존 아임웹 제작 사이트를 우선하도록 요청해 후속으로 미룹니다. 네이버는 서치어드바이저 기반 소유확인·수집·페이지 정보·사이트맵·해당 RSS·제출·색인 상태 검증까지만 포함합니다. 플레이스·블로그·광고·리뷰 운영은 제외합니다.

## 실행의 선행 조건

- -1단계에서 실제 제어 범위를 언어별로 실측합니다. canonical 편집 가능·추가만 가능·모두 불가·미확인에 따라 대표 주소 4A를 분기합니다.
- 신규 canonical을 추가해 기존 자동 태그와 충돌시키는 수정은 금지합니다. 설명문 4B와 다른 지원 수단은 독립적으로 판단합니다.
- 실제 변경 전 비공개 관리자 원문 백업·복구 시험·기준선·사전 승인이 필요합니다.
- 상세 정책은 [실행·검수 기준](07-IMPLEMENTATION-POLICIES.md), 일정은 [작업 순서](04-WORKFLOW.md)를 따릅니다.

## 해결할 일

1. 잘못 연결된 국가별 페이지 주소를 바로잡습니다.
2. 한 페이지에 여러 개 생기는 검색 제목을 정리합니다.
3. 홈페이지 대표 주소와 검색 설명의 불일치를 검토합니다.
4. 구조화된 정보가 화면 내용과 같은 사실을 말하는지 확인합니다.
5. 이미지 목록을 만들고 부자연스러운 인물·오래된 타이틀 이미지의 교체 후보를 분류합니다.
6. 새 이미지는 페이지 주제, 언어, 표시 크기, 용량, 대체 설명을 함께 관리합니다.

## 하지 않을 일

- SEO를 이유로 사이트를 새로 디자인하지 않습니다.
- 순위를 위해 숨겨진 문장이나 키워드를 넣지 않습니다.
- 확인되지 않은 효능·기간·안전성·후기·평점을 만들지 않습니다.
- 메뉴·슬라이더·애니메이션·예약·상담 코드를 한꺼번에 정리하지 않습니다.
- 태국어 사이트를 수정하지 않습니다.
- 사용자 승인 없이 아임웹에 저장하거나 게시하지 않습니다.

## 완료 조건

- 변경 주소가 실제 200이고, 각 언어 페이지가 서로 올바르게 연결됩니다.
- 페이지당 의도한 검색 제목과 대표 주소가 모순 없이 출력됩니다.
- 모바일과 PC에서 변경 전후 화면 차이가 허용 범위 안에 있습니다.
- 메뉴·FAQ·언어 이동·상담 링크가 기존처럼 작동합니다.
- PC·모바일 전후 각 5회 중앙값에서 LCP +10% 초과·CLS 0.1 초과는 반려합니다. 그 이하라도 재현 가능한 악화가 없어야 합니다.
- 모든 변경에 원본, 이유, 영향 범위, 검증 결과, 복구 방법이 기록됩니다.

검색 순위나 AI 답변 인용의 증가를 코드만으로 보장하지 않습니다. 실제 성과는 Google Search Console과 네이버 서치어드바이저 데이터가 연결된 뒤 별도로 판단합니다.

## 개선 목표

기존 479 URL 재검사에서 복수 title 77페이지→0, 추가 title 143요소→0을 목표로 합니다. 작업 상태는 143위젯 단위로 관리합니다. 알려진 잘못된 언어 연결 3개를 해소하고, 확정 다국어 묶음의 자기·상호참조 오류 0건과 검사 범위를 함께 보고합니다. x-default는 필수 태그로 취급하지 않고 승인된 정책을 따릅니다.

루트·home의 실제 중복 색인은 아직 미확인입니다. 5언어의 대표 주소 신호와 10 URL의 Google 선택 주소를 대조하고, GSC 색인 대상 대표 URL의 상태 변화를 관찰합니다. 미검사·제어 불가 항목을 분모에서 빼거나 해결한 것으로 계산하지 않습니다.
