# 1. 목표와 원칙

## 한 문장 목표

뷰티블라썸의 5개 언어 사이트가 Google과 네이버에 정확히 이해되도록 검색 정보를 정리하고, 오래되거나 부자연스러운 이미지는 검토를 거쳐 교체하되 기존 디자인·기능·속도를 보호합니다.

## 대상

- 한국어: `beautyblossom.kr`
- 영어: `en.beautyblossom.kr`
- 일본어: `jp.beautyblossom.kr`
- 중국어 간체: `cn.beautyblossom.kr`
- 중국어 번체: `tw.beautyblossom.kr`

태국어 사이트는 이번 단계에서 제외합니다.

## 해결할 일

1. 잘못 연결된 국가별 페이지 주소를 바로잡습니다.
2. 한 페이지에 여러 개 생기는 검색 제목을 정리합니다.
3. 홈페이지 대표 주소와 검색 설명의 불일치를 검토합니다.
4. 구조화된 정보가 화면 내용과 같은 사실을 말하는지 확인합니다.
5. 이미지 목록을 만들고 부자연스러운 인물·오래된 타이틀 이미지의 교체 후보를 분류합니다.
6. 새 이미지는 페이지 주제, 언어, 표시 크기, 용량, 대체 설명을 함께 관리합니다.

## 하지 않을 일

- SEO를 이유로 사이트를 새로 디자인하지 않습니다.
- 순위를 위해 숨겨진 문장이나 키워드를 넣지 않습니다.
- 확인되지 않은 효능·기간·안전성·후기·평점을 만들지 않습니다.
- 메뉴·슬라이더·애니메이션·예약·상담 코드를 한꺼번에 정리하지 않습니다.
- 태국어 사이트를 수정하지 않습니다.
- 사용자 승인 없이 아임웹에 저장하거나 게시하지 않습니다.

## 완료 조건

- 변경 주소가 실제 200이고, 각 언어 페이지가 서로 올바르게 연결됩니다.
- 페이지당 의도한 검색 제목과 대표 주소가 모순 없이 출력됩니다.
- 모바일과 PC에서 변경 전후 화면 차이가 허용 범위 안에 있습니다.
- 메뉴·FAQ·언어 이동·상담 링크가 기존처럼 작동합니다.
- 같은 조건의 반복 측정에서 의미 있는 속도 저하가 없습니다.
- 모든 변경에 원본, 이유, 영향 범위, 검증 결과, 복구 방법이 기록됩니다.

검색 순위나 AI 답변 인용의 증가를 코드만으로 보장하지 않습니다. 실제 성과는 Google Search Console과 네이버 서치어드바이저 데이터가 연결된 뒤 별도로 판단합니다.
