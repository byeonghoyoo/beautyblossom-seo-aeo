# 5. Claude Code 작업 지시

Claude Code는 구현 담당자이고, Codex는 기획·작업 지시·결과 검수를 담당합니다.

## 필수 지시문

> 승인된 항목과 지정된 파일·아임웹 필드만 수정한다. 작업 전 원문과 설정값을 보관하고, 변경 전후 차이를 한국어로 먼저 제시한다. 디자인 DOM, CSS, 메뉴, 예약, 상담, 언어 이동, 애니메이션, 추적 코드, 리소스 로드 순서를 임의로 바꾸지 않는다. 신규 외부 라이브러리나 반복 실행 코드를 추가하지 않는다. 확인되지 않은 의료 효능·기간·안전성·가격·후기·평점을 작성하지 않는다. 이미지 생성물은 실제 환자·의료진·시술 결과로 오인시키지 않으며 사용 승인 상태를 기록한다. 모바일·PC 화면, 주요 기능, 검색 메타데이터, 반복 성능 비교와 복구 절차를 제출한다. 자동 저장·자동 게시·권한 변경을 하지 않는다. 불명확하면 추측하지 말고 작업을 멈추고 보고한다.

## 작업 결과에 반드시 포함할 것

1. 변경한 페이지와 위젯 또는 관리자 필드
2. 변경 전 원문 위치와 복구본
3. 변경 이유와 사용자에게 보이는 영향
4. 실행한 검사와 실제 결과
5. 남은 위험과 확인하지 못한 항목

## 금지 표현

- 실제 측정 없이 “속도가 빨라졌다”
- 검색 성과 자료 없이 “순위가 오른다”
- JSON 문법만 보고 “구조화 데이터가 완벽하다”
- 화면 하나만 보고 “모든 기기에서 디자인이 같다”
- AI 탐지기의 점수만 보고 “AI 이미지가 확실하다”

## 작업 단위

현재 실행 정책은 [실행·검수 기준](07-IMPLEMENTATION-POLICIES.md)과 [단계별 일정](04-WORKFLOW.md)을 먼저 확인합니다.

- -1단계의 언어별 제어 결과가 없는 항목을 구현하지 않습니다. canonical 추가만 가능한 상태에서 두 번째 태그를 넣지 않습니다.
- 관리자 before·rollback 원문 전체를 공개 Git에 커밋하지 않습니다. 비공개 복구본 ID와 검토된 최소 diff를 연결합니다.
- 복수 title은 143위젯의 공통 출력 유형으로 수정 절차를 재사용하되, head·body 전체 자동 삭제는 하지 않습니다. 77페이지 영향 검수를 별도로 합니다.
- 소프웨이브 hreflang은 5언어 자기·상호참조를 내부 완료선으로 검증합니다. x-default를 Google 필수 조건이라고 쓰지 않습니다.
- PC·모바일 각각 전후 5회 중앙값으로 LCP·CLS를 비교합니다. +10% 초과·0.1 초과 또는 그 이하의 재현 가능한 악화는 반려하며 미측정은 보류합니다.
- 네이버는 별도 웹사이트 기술 검증 트랙입니다. 자동 제출·블로그 발행·플레이스 변경은 범위 밖입니다.

검색 정보 수정과 이미지 교체는 같은 커밋에 섞지 않습니다. 문제가 생겼을 때 원인을 정확히 되돌릴 수 있도록 국가·페이지·목적별로 작은 변경을 유지합니다.
