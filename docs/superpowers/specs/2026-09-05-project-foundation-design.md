# 뷰티블라썸 SEO·AEO 통합 저장소 설계

## 목적

직장 데스크톱과 Codex가 같은 조사 결과·기획·검수 기록을 안전하게 공유하도록 비공개 GitHub 저장소를 구성한다. 첫 화면과 핵심 문서는 일반인이 이해할 수 있는 표현을 쓰며, 상세 데이터는 검증 가능한 표와 JSON으로 분리한다.

## 범위

- PRD, 사용 도구, 저장 구조, 작업 흐름, Claude Code 지시, 검수 로그를 고정 순서로 제공한다.
- 프로젝트 지도와 안전한 변경 흐름을 GitHub에서 바로 렌더링되는 Mermaid로 제공한다.
- 5개 언어 감사의 핵심 집계와 페이지·제목·이미지·헤딩 목록을 보관한다.
- 전체 원본 HTML은 저장하지 않고 상대 경로·크기·SHA-256 목록으로 추적한다.
- 이미지 작업을 후보·시안·승인으로 분리한다.

## 안전 조건

- 인증 정보, 관리자 민감정보, 승인되지 않은 인물 원본을 커밋하지 않는다.
- 아임웹 자동 저장·게시·권한 변경을 수행하지 않는다.
- `main`과 기획 브랜치를 워크트리로 분리한다.
- 보고서 수치, 파일 링크, 대상 언어, 원본 제외 여부를 자동 검사한다.

## 저장 구조

`docs`는 사람이 읽는 순서, `audit`은 근거, `assets`는 이미지 승인 상태, `tools`와 `tests`는 재검증을 담당한다. 각 파일의 책임은 `docs/03-ARCHITECTURE.md`에 정의한다.

## 성공 조건

- README에서 모든 주요 문서와 데이터 영역에 접근할 수 있다.
- 530·479·77·143 등 핵심 집계가 저장 데이터와 문서에서 모순되지 않는다.
- 태국어가 페이지 목록과 원본 매니페스트에서 제외된다.
- 전체 HTML 압축 원본이 저장소에 포함되지 않는다.
- GitHub 변경 검토 화면을 통해 `main`에 합치기 전에 내용을 확인할 수 있다.
