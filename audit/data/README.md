# 감사 데이터 안내

이 폴더는 사람이 읽는 보고서를 다시 확인할 수 있는 집계 자료를 보관합니다.

- `summary.json`: URL 수, 복수 title, 코드 위젯, 구조화 정보 유형 집계
- `browser-observations.json`: 관리자 코드 위치와 실제 브라우저 DOM 표본 관찰
- `validated-urls.json`: 404 및 아임웹 기본 도메인 대표 주소 확인 결과
- `source-evidence-manifest.csv`: GitHub에 올리지 않은 로컬 원본의 경로·크기·SHA-256

`source-evidence-manifest.csv`의 파일이 이 저장소에 존재한다는 뜻은 아닙니다. 로컬 증거가 바뀌었는지 확인하기 위한 목록이며, 개인 컴퓨터의 절대 경로는 기록하지 않습니다.
